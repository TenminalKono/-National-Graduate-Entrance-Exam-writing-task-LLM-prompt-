使用方法

prompt：小作文请替换第一段的写作指示和文体（默认为article），大作文仅需要上传漫画图片和prompt

写作模板：加粗部分为词伙/值得积累句子(素材)，大部分模板为prompt跑出来的历年真题文章，小部分使用了雅思范文和辅导材料中的文章。大作文的话题分类参考了雅思写作的话题。
